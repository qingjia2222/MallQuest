# 3–5 分钟主演示

1. 运行 `run_demo.ps1`，打开 Web 与微信开发者工具。
2. 小程序连接 QD square，展示 `mall_demo` 和 Demo 地图标识。
3. 问“停车场还有空位吗？”展示 247 个演示空位及三区数据。
4. 问“积分多久过期？”展示答案和 `points_rules.md` 来源。
5. 输入约会标准句，展示状态历史、三站行程和跨层 Dijkstra 路线。
6. 点击确认，展示预约、领券和电影票数据库结果。
7. 点击播报，播放本地普通话行程摘要。
8. Web 用 `demo/demo123` 登录，展示同一用户的计划/预约数据。
9. 快速展示五场景自动测试与 `/api/debug/metrics`。

现场不要临时更换标准句或打开千问 online，除非已经运行 `verify_online_llm.py` 成功。
