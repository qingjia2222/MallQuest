# 5 分钟商业闭环主演示

1. 运行 `run_demo.ps1`，微信开发者工具重新编译，先展示游客/会员、商户、管理者三个独立入口。
2. 进入商户端，输入 `QD-S01-DEMO`，把蜀香小院设为“客流繁忙”、排队 36 分钟，发布一条优惠；退出回三方入口。
3. 进入游客端并连接 QD square，在地图点击蜀香小院，证明营业/排队/优惠已即时同步。
4. 在问答输入“从当前位置怎么去电影院？”，屏幕背景变暗并自动弹出 2.5D 路线，红点从当前位置移动到影院；演示重播和关闭。
5. 再问“今天有什么优惠？”，强调普通攻略/业务问答不会误弹地图；输入约会标准句，确认后执行预约、领券和购票。
6. 从游客端退出，进入管理者端，用 `manager / manager123` 登录，切换日/月/年看板，展示 Mock 标识、客流/营收/实时监测。
7. 创建一家入驻店铺并获得店铺编码，再提交平面图数字化任务，说明当前生成可编辑 2.5D 初稿、上线前需人工校准。
8. 收尾展示 12+ 项自动测试、RAG 来源、千问在线验证和本地普通话 TTS，说明未来正式前端、真实地图和业务数据库可沿冻结接口替换。

录屏优先使用微信开发者工具以保证稳定；只有在 `verify_online_llm.py` 已成功且网络稳定时才现场切千问 online。经营数据和地图必须明确标注 Demo/Mock。
