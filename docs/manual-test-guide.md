# 星河里 完整手工测试顺序

## 一、开始前检查

1. 浏览器打开 `http://127.0.0.1:8000/health`。看到 `code: 0` 和 `status: up` 表示后端已经运行，不要重复双击启动脚本。
2. 如果打不开，再从项目根目录双击 `run_demo.ps1`，并保持出现的 PowerShell 窗口开启。
3. 微信开发者工具打开 `E:\shixi\llm\小组作业2\app`，点击“编译”。
4. “详情 → 基本信息”应显示真实小程序 AppID；公共文件中的 `touristappid` 会由本地、已忽略的 `project.private.config.json` 覆盖。

## 二、先在开发者工具完成主链测试

### 1. 三方入口

- 首屏应显示游客/会员、商户、商场管理者三张位于同一卡组的入口卡。
- 三张卡之间不应出现紫色背景分界线。
- 登录后不应出现角色切换按钮；退出后才返回三方入口。

### 2. 模拟 AI 服务二维码进入

1. 点击顶部“普通编译”下拉菜单，添加编译模式。
2. 启动页面填写 `pages/scan/scan`。
3. 启动参数填写 `scene=QD-AI-DEMO`。
4. 保存并编译。
5. 页面应显示“已识别 AI 服务二维码 · QD-AI-DEMO”。
6. 输入手机号 `11111111111`、密码 `123456`。
7. 应依次看到“正在连接私有数据”“已连接 星河里”“AI 私域数据已就绪”，然后进入对话页。

### 3. 游客问答与格式

依次输入：

- `停车场还有空位吗？`：应查询并展示停车数据。
- `我的积分多久过期？`：应返回积分规则，并带知识库来源。
- `今天有什么优惠？`：应返回当前商场特惠。
- `从当前位置怎么去电影院？`：应自动弹出暗色遮罩上的路线动画，小红点移动到 QD 星幕影院；“重播路线”和“关闭导览”均应可用。

检查所有 AI 回复：界面中不应出现 `*` 或 `**`。普通优惠、积分和攻略问答不得误弹路线动画。

### 4. 规划与事务

输入：`今晚7点两个人约会，人均250，想吃川菜，还想看电影。`

- 应生成方案并进入确认阶段。
- 查看方案与路线。
- 未确认前不得写入预约、券或票。
- 点击确认后，应看到预约、领券和购票结果。

### 5. 商户入口

1. 退出游客端，进入商户登录。
2. 输入店铺编码 `QD-S01-DEMO`。
3. 应只看到蜀香小院工作区。
4. 修改营业状态、排队分钟和可用座位并保存。
5. 发布一条测试优惠。
6. 返回游客端查询蜀香小院，刚才的数据应立即可见。

### 6. 管理者入口

1. 退出并进入商场管理者。
2. 账号 `manager`，密码 `manager123`。
3. 切换日度、月度、年度，图表都应有数据并明确标注 Mock。
4. 创建测试店铺，应获得店铺编码。
5. 提交平面图任务，应返回 2.5D 初稿状态和人工校准提示。

## 三、手机扫码测试

### 当前开发阶段的可靠方式

1. 在开发者工具中选中前述 `scene=QD-AI-DEMO` 自定义编译模式。
2. 重新编译后点击顶部“预览”。
3. 用已加入该小程序开发成员的微信，立即扫描开发者工具刚生成的预览码。
4. 手机应直接拉起游客手机号登录页，并保留 `QD-AI-DEMO` 场景。

开发版二维码会过期；出现“开发版本小程序已过期，请在开发者工具重新扫码”时，重新点击“预览”获取新码即可。固定的 AI 服务码只有在小程序设为体验版或正式发布后才适合长期展示。

### 当前手机测试边界

上传版小程序中的后端地址目前是 `http://127.0.0.1:8000`。手机的 `127.0.0.1` 指向手机自身，因此当前手机只用于验证“扫码拉起和场景传递”；完整登录、问答和地图联调请先在开发者工具模拟器完成。若要手机跑完整链路，需要把 API 地址替换为手机可访问的 HTTPS 地址并在微信后台配置合法域名，然后重新上传。

## 四、录屏推荐顺序

1. 展示 AI 服务二维码或开发者工具预览码。
2. 切开发者工具，模拟扫码并用手机号登录。
3. 展示私有数据源连接动画。
4. 问停车和积分。
5. 问“怎么去电影院”，展示路线动画、重播和关闭。
6. 完成约会规划与确认。
7. 快速切换商户状态更新和管理者经营看板。

## 五、常见故障

- 上传按钮灰色：项目以 `touristappid` 打开；重新运行 `server/scripts/configure_wechat_project.py` 后关闭并重开项目。
- 登录返回 404：8000 端口运行的是旧后端；关闭旧 Python/PowerShell 后重新运行 `run_demo.ps1`。
- 登录提示连接失败：先访问 `http://127.0.0.1:8000/health`，确认后端窗口没有关闭。
- 开发版二维码过期：重新编译并点击“预览”，扫描新码。
- 手机能打开但登录失败：这是 localhost 网络边界，需要 HTTPS 后端地址，不是手机号或二维码解析错误。
