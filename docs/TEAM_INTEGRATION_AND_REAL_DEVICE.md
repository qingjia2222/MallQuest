# 星河里：甲乙整合与微信真机运行指南

## 1. 数据整合原则

甲组提供的 `web/src/store/*.json` 是前端地图几何和展示资料，不是实时业务数据库；乙组的 `server/data/mall.db` 是店铺、会员、排队、优惠、预约、停车与经营数据的主数据源。

本次采用“整合而非覆盖”：

- 保留甲组 3D 地图外观、楼层、店铺块、卫生间、入口、扶梯等公共设施。
- 后端新增 `store_map_bindings`，把乙组 22 家业务店铺绑定到甲组地图槽位、楼层和 3D 坐标。
- `/api/maps/{mall_id}/scene` 同时返回实时店铺字段和 `map_slot/map_x/map_z/map_width/map_depth`。
- 路线动画优先使用后端绑定坐标；旧 JSON 坐标作为兼容兜底。因此甲组以后替换地图，只需更新绑定，不必删除问路、红点动画或业务接口。
- 店铺营业、排队、余位、优惠、会员和预约始终以后端数据库为准；甲组额外的装饰店铺/公共设施继续作为地图展示内容保留。

## 2. 甲组完成的内容

- 微信小程序与 Web 前端框架、主题视觉和四栏导航。
- 首页、对话、规划、我的等主要页面外观。
- 富卡片、规划进度和停车仪表盘等前端组件。
- Three.js 3D 商场地图、楼层切换、旋转缩放、店铺块和前端地图资料。

## 3. 乙组完成的内容

- FastAPI、统一响应 envelope、手机号/微信/商家/管理者分角色登录和商场数据隔离。
- AI 服务二维码绑定商场私有数据源。
- 千问 LLM 适配器、工具调用、意图/槽位/会话、离线 scripted 兜底。
- Planner 多步状态机、路线构建、RAG 积分规则和业务工具注册表。
- SQLite 店铺/商户/会员/优惠/票务/预约/停车/经营分析数据及 Seed。
- 游客问地点时自动弹出地图，背景变暗，红点从当前位置移动到目的地；支持跨层、重播和关闭。攻略问答不会误触发路线动画。
- 商家维护营业、排队和优惠信息，管理者查看实时/日/月/年经营看板，以及接口测试和演示启动脚本。

## 4. 本次适配结果

- Web 和微信小程序统一为“星河里 · 购物中心”及“首页 / 对话 / 规划 / 我的”。
- 外观以甲组为准；乙组功能通过 API、地图绑定和路由动画控制层接入。
- 日常启动不再删除 `mall.db`，避免后端占用数据库时因 Windows 文件锁启动失败。
- 小程序的 API、语音文件和楼层 SVG 全部使用同一个可配置的 `BASE_URL`，不再遗漏硬编码 localhost。

## 5. 微信真机（同一 Wi-Fi）启动顺序

1. 电脑和手机连接同一个 Wi-Fi；不要使用相互隔离的访客网络。
2. 在项目根目录右键 `configure_mini_lan.ps1`，选择“使用 PowerShell 运行”。如果仍被记事本打开，在 PowerShell 执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\configure_mini_lan.ps1
   ```

3. 启动后端和 Web：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\run_demo.ps1
   ```

   保持这个窗口打开。后端监听 `0.0.0.0:8000`，脚本会打印电脑和手机可访问的地址。

4. 先在电脑浏览器访问 `http://127.0.0.1:8000/health`。再在手机浏览器访问脚本打印的 `http://局域网IP:8000/health`。两处都应看到健康状态。
5. 微信开发者工具导入 `E:\shixi\llm\小组作业2\app`，点击“编译”。开发阶段在“详情 → 本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
6. 使用开发者工具的“预览”二维码扫码，或上传新的开发版本后在微信公众平台“版本管理 → 开发版本”选最新版体验。
7. 扫 AI 服务二维码时页面路径为 `pages/scan/scan`，参数为 `scene=QD-AI-DEMO`。普通体验二维码进入后也可正常登录，再由入口完成数据源绑定。
8. 用户端 Mock 登录：手机号 `11111111111`，密码 `123456`。商家和管理者登录方式保持不变。

## 6. 常见真机网络问题

- 电脑健康检查成功、手机失败：优先检查两端是否同一 Wi-Fi、Windows 防火墙是否允许 Python 监听专用网络，以及路由器是否开启 AP 隔离。
- IP 改变：重新运行 `configure_mini_lan.ps1`，然后重新编译/上传。
- 开发者工具可用、上传版请求失败：局域网 HTTP 只适合课程现场开发联调。正式发布必须部署 HTTPS，并在微信公众平台配置 `request` 合法域名；不能把 `127.0.0.1`、局域网 IP 或纯 HTTP 当作正式域名。
- `404 /api/auth/phone-login`：通常是旧后端进程或启动目录不对。关闭占用 8000 端口的旧进程，再从本项目根目录运行 `run_demo.ps1`。
- 数据库文件锁：日常脚本现在不会删除数据库。只有执行测试或显式重置时才需要先关闭运行中的后端。
